**Device:** Samsung Galaxy Tab A 10.1 (2019) Wi-Fi, **SM-T510 only**, on stock firmware **T510XXU5CWA1**.
**Install:** see [INSTALL.md](https://github.com/mad-001/sm-t510-lineageos/blob/main/docs/INSTALL.md). Unzip the `.img.xz` and flash the `.img` to **System Image** in TWRP.
**Check the download:** `sha256sum -c <file>.img.xz.sha256`

This build is provided **as is**. There are **no feature requests**. If you want something different, the full build recipe is in this repository; build it yourself.
