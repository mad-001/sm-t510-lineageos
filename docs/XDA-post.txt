[SIZE=5][B]What is this[/B][/SIZE]

[SIZE=5][B]Installation (clean install from stock)[/B][/SIZE]
Put the unzipped .img and the Multidisabler zip on your microSD card first.
[LIST=1]
[*][B]Unlock the bootloader[/B] (wipes the tablet): follow the guide linked above. Short version: Developer options > OEM unlocking on; power off; hold Vol Up + Vol Down and plug in USB; on the light-blue screen long-press Vol Up, then press Vol Up to confirm. After the wipe, set up, connect to Wi-Fi and check OEM unlocking says the bootloader is already unlocked.
[*][B]Install TWRP[/B]: Download mode (Vol Up + Vol Down + plug in USB, short-press Vol Up). In Odin load the TWRP .tar.md5 in AP, untick Auto Reboot, Start. Then hold Power + Vol Down until black and immediately hold Power + Vol Up to boot straight into TWRP. If stock boots first, it restores the stock recovery; repeat.
[*]In TWRP: [B]Install[/B] > Multidisabler zip.
[*][B]Wipe > Format Data[/B] > type yes. Then [B]Reboot > Recovery[/B].
[*][B]Wipe > Advanced Wipe[/B]: Dalvik/ART Cache, Cache, System, Data.
[*][B]Install > Install Image[/B] > lineage-23.2-...img > [B]System Image[/B].
[*]Optional: Wipe > Advanced Wipe > System > Repair or Change File System > [B]Resize File System[/B].
[*][B]Reboot > System[/B]. The first boot takes a few minutes.
[/LIST]
[B]Updating[/B] from an earlier build of this ROM: TWRP > Install > Install Image > new .img > System Image > reboot. No wipe needed.
Full guide: [URL='https://github.com/mad-001/sm-t510-lineageos/blob/main/docs/INSTALL.md']INSTALL.md on GitHub[/URL]
